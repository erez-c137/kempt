# Code of Conduct

Kempt is a small project, so the rules are short:

- Be decent to each other. Disagree with ideas, not with people.
- Keep it on topic: updates, packages, Plasma, the code.
- No harassment, no personal attacks, no spam.

If someone crosses a line, email the maintainer at <erez.c137@protonmail.com>. That report is not
filed as an issue and is not made public: a GitHub issue is visible to everybody, which is the
wrong place to name what happened to you. Reports are handled privately and in good faith. The
maintainer may edit, lock or remove content and, if needed, block accounts. That is the whole
document.
