# Code of Conduct

Kempt is a small project, so the rules are short:

- Be decent to each other. Disagree with ideas, not with people.
- Keep it on topic: updates, packages, Plasma, the code.
- No harassment, no personal attacks, no spam.

If someone crosses a line, open an issue or contact the maintainer (@erez-c137); reports are handled privately and in good faith. The maintainer may edit, lock or remove content and, if needed, block accounts. That is the whole document.
