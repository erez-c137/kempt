# Icon candidates

Raw explorations only (any format, any name). Nothing here ships.

- Drop generated logo/app-icon candidates in this folder.
- The bake-off's hand-drawn 16 px-grid concept SVGs and legibility sheets live one level up.
- When a candidate wins it is redrawn as clean SVG and moves to its shipping home:
  - full-colour app icon: `plasmoid/contents/icons/kempt.svg` (referenced by
    `metadata.json` as `"Icon": "kempt"`), plus PNG exports for the README and store listing
  - panel glyph: `plasmoid/contents/icons/kempt-symbolic.svg` (monochrome, Breeze style,
    legible at 16 and 22 px)
